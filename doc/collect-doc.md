The negotiation between `Engine` and `Broker` in BBDO 3, the centralized configuration and the groundwork for the Poller HA are described apart from this API documentation, in the Markdown documents of `doc/nego-engine-broker/` (one file per chapter, in English and in French, `README-en.md` being the index). They are best read on GitHub, which renders their diagrams, or as a PDF built by `doc/generate-pdf.sh`.
